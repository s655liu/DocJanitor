# 🧹 Auto-Doc Janitor

**The Autonomous Documentation Cleaner for Modern AI Workflows.**

Auto-Doc Janitor is a background agent designed for the Google Antigravity ecosystem. It solves "Documentation Debt" by using a multi-model reasoning loop to keep `STRUCTURE.md` and `ARCHITECTURE.md` perfectly synced with your code in real-time — directly inside **Cursor** or **VS Code**.

## 🚀 Features

- **Autonomous Background Agent**: Runs silently in the background, watching your filesystem for changes.
- **Multi-Document Suite**: Orchestrates updates across any number of `.md` files (API refs, Onboarding guides, ADRs) via `.janitor.config.json`.
- **Nia Context Grounding**: Queries Nia's semantic search to retrieve project-level context (Docs, specs) before generating patches.
- **Surgical Documentation Patching**: Instead of regenerating whole files, the Janitor uses AI to patch only the relevant sections.
- **Agentic Interoperability**: Automatically links with `CLAUDE.md`, `GEMINI.md`, etc., to ground other AI assistants.
- **Premium Sidebar UI**: Real-time visual feedback with a "Processing" pulse and detailed change-tier analysis.

## 🤖 Dual-Model Strategy (Powered by CLōD)

- **Gemini 3.1 Flash**: Used for **Minor Tiers** (function renames, small diffs) for sub-second documentation patches.
- **Gemini 3.1 Pro**: Triggered for **Major Tiers** (new modules, structural shifts) to generate high-level architectural insights.

## 💎 Sponsor Integrations

- **🟢 CLōD**: Dynamic model routing based on changeset complexity.
- **🔵 Nia by Nozomio**: Context grounding to understand *why* code changed (Slack threads, PDF specs).
- **🟠 AllScale**: Feature gating for "Full-Repo Regeneration" via simulated micropayments.
- **⚪ Greptile**: Self-auditing of internal IPC logic and socket handling.

## 🛠️ Installation & Setup

### 1. Prerequisites
- Python 3.9+
- VS Code or Cursor

### 2. Python Agent Setup
```bash
# Clone the repository
git clone https://github.com/s655liu/DocJanitor.git
cd DocJanitor

# Install dependencies
pip install -r requirements.txt

# Configure environment
cp .env.example .env
# Open .env and add your CLOD_API_KEY
```

### 3. Extension Setup
```bash
cd extension
npm install
npm run compile
```

### 4. VS Code Configuration
1. Open VS Code **Settings** (Ctrl + ,).
2. Search for `Janitor Python Path`.
3. Set it to your Python executable (e.g., `C:\Users\Name\miniconda3\python.exe` or simply `python`).

## 🕹️ Usage

1. **Launch**: Press `F5` in VS Code to start the extension.
2. **Watch**: The Janitor sidebar will appear. It starts watching your `WATCH_PATH` (defaults to current project).
3. **Code**: Just write code! When you save a file:
   - The sidebar pulses **blue** during analysis.
   - `STRUCTURE.md` is updated automatically.
   - Other AI assistants (Claude/Cursor) are notified via their respective rule files.
